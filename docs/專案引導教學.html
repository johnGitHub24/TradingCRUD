三層架構

flowchart TB subgraph Frontend["Vue 3 前端"] LV[LoginView] OV[OrdersView] API[api/client.js] end subgraph Transport["傳輸層"] VITE[Vite :5173 dev] BFF[Node BFF :3000 prod] end subgraph Backend["Spring Boot :8083"] AC[AuthController] OC[OrderController] OS[OrderService] REPO[OrderRepository] end DB[(H2 / PostgreSQL)] LV --> API OV --> API API --> VITE API --> BFF VITE --> AC VITE --> OC BFF --> AC BFF --> OC AC --> OS OC --> OS OS --> REPO REPO --> DB

Vue 前端結構

檔案職責
src/views/LoginView.vue登入表單 → POST /auth/login
src/views/OrdersView.vue訂單 CRUD 表格 + Modal
src/api/client.jsAxios + JWT interceptor
src/stores/auth.jsToken 存 localStorage
src/router/index.js路由守衛（需登入）

Spring Boot 分層

套件代表類別職責
authAuthController, AuthService登入、JWT 簽發
orderOrderController, OrderServiceCRUD + 批次
securityJwtService, JwtAuthenticationFilterToken 驗證
infrastructureOrderEntity, OrderRepositoryJPA 落庫
commonGlobalExceptionHandler統一錯誤格式

JWT 認證流程

sequenceDiagram participant V as Vue LoginView participant A as AuthController participant S as AuthService participant J as JwtService V->>A: POST /auth/login A->>S: login() S->>J: generateToken() J-->>V: accessToken Note over V: localStorage 儲存 V->>A: GET /orders + Bearer Note over A: JwtAuthenticationFilter 驗證

訂單 CRUD 流程

sequenceDiagram participant V as OrdersView participant C as OrderController participant S as OrderService participant R as OrderRepository V->>C: POST /orders C->>S: create() S->>R: existsByClientOrderId? S->>R: save() R-->>V: 201 OrderResponse

前後端 API 對照

前端函式後端端點權限
login()POST /api/v1/auth/login公開
fetchOrders()GET /api/v1/orders已登入
createOrder()POST /api/v1/ordersADMIN
updateOrder()PUT /api/v1/orders/{id}ADMIN
deleteOrder()DELETE /api/v1/orders/{id}ADMIN
batchCreateOrders()POST /api/v1/orders/batchADMIN

詳見 docs/前後端串接說明.md

驗證四層

層機制錯誤
L1 傳輸JWT + @PreAuthorize401 / 403
L2 格式@Valid on DTO400 VALIDATION_FAILED
L3 業務Service 冪等檢查409 DUPLICATE_ORDER
L4 資料DB UNIQUE最後防線
