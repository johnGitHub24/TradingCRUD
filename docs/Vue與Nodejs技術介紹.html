3. Vue.js 是什麼？

Vue.js 是建構使用者介面的 JavaScript 框架。核心：資料驅動畫面——改資料，畫面自動更新。

3.1 與傳統 HTML/JS 的差異

傳統做法Vue 做法
getElementById 改文字{{ username }} 綁定變數
手動建立表格列v-for 遍歷陣列
自己寫跳頁Vue Router 管理網址
到處複製 fetchapi/client.js 集中封裝

3.2 單檔元件 .vue

<template>  <!-- HTML 樣板 -->
<script setup>  // JavaScript 邏輯
<style scoped>  /* 選用樣式 */

範例：LoginView.vue、OrdersView.vue

3.3 核心概念

概念說明本專案
ref()響應式變數；script 用 .value登入表單 username
computed()依賴變動自動重算isLoggedIn
onMounted()元件掛載後執行載入訂單列表
v-model雙向綁定表單帳密輸入
v-if / v-for條件 / 迴圈渲染ADMIN 按鈕、表格
@submit.prevent阻止表單預設跳頁登入送出
unref 陷阱：isLoggedIn 是 ComputedRef。在 router/index.js 必須用 unref(auth.isLoggedIn)，否則會無限 401 循環。詳見 stores/auth.js 註解。

網址元件說明
/loginLoginView.vue訪客頁
/ordersOrdersView.vue需登入
/redirect導向 /orders

4. Vite 開發與打包

cd frontend
npm install    # 第一次
npm run dev    # → http://localhost:5173/login
功能說明
HMR 熱更新改 .vue 存檔，瀏覽器即時更新
ES Module啟動快，不需整包打包
Proxy/api 轉發到 :8083，避免 CORS

vite.config.js 關鍵設定

server: {
  port: 5173,
  open: '/login',
  proxy: {
    '/api': {
      target: 'http://localhost:8083',
      changeOrigin: true
    }
  }
}
指令用途
npm run dev開發伺服器 :5173
npm run build打包到 server/public/
npm run preview預覽 build 結果

5. Axios 與 API 層

LoginView / OrdersView
        ↓ export function
api/client.js（攔截器 + JWT）
        ↓ HTTP
Vite proxy 或 Node BFF
        ↓
Spring Boot REST API

攔截器

  • Request：自動加 Authorization: Bearer <token>
  • Response 401：登出並導向 /login（登入 API 除外）
函式HTTP說明
login(u, p)POST /auth/login取得 JWT
fetchOrders(params)GET /orders分頁列表
createOrder(body)POST /orders新增（ADMIN）
updateOrder(id, body)PUT /orders/{id}更新（ADMIN）
deleteOrder(id)DELETE /orders/{id}刪除（ADMIN）
batchCreateOrders()POST /orders/batch批次新增
batchDeleteOrders()DELETE /orders/batch批次刪除

6. 認證狀態 stores/auth.js

欄位存放用途
token記憶體 + localStorageJWT
username同上導覽列顯示
role同上ADMIN 才能寫入
方法時機
setSession({ accessToken, username, role })登入成功
logout()登出或 Token 失效

7. Node.js 與 Express BFF

Node.js 讓 JavaScript 在伺服器端執行。本專案兩種用途：

用途指令埠
Vite 開發工具npm run dev（frontend/）5173
Express BFFnpm start（server/）3000

BFF 架構（server/server.js）

瀏覽器 → localhost:3000
  ├─ GET /orders      → index.html（SPA）
  ├─ GET /assets/*    → 靜態 JS/CSS
  └─ /api/v1/*        → proxy → :8083

Express 中介層順序

  1. cors() — 跨來源
  2. express.json() — 解析 JSON
  3. /api proxy — 轉發 Spring Boot
  4. express.static — 靜態檔
  5. SPA fallback — 其餘回 index.html

啟動 BFF

.\gradlew.bat bootRun
cd frontend && npm run build
cd ..\server && npm install && npm start
→ http://localhost:3000/login

12. 常見問題 FAQ

問題原因解法
Authentication required 重複跳Router 未 unref見 router + auth.js
:5173 連不上前端未啟動npm run dev / Full Stack
API Network Error後端未跑bootRun / TradingCrudApplication
CORS 錯誤直連 :8083用 /api/v1 走 proxy
:3000 空白未 build先 npm run build
H2 90149 test not foundJDBC URL 錯改 jdbc:h2:mem:tradingcrud

13. 與後端（Java）的分工

層技術負責
畫面與互動Vue 3表單、表格、路由、Token 存放
傳輸Vite / Node proxy轉發 /api
商業邏輯與安全Spring BootJWT 驗證、CRUD、權限
資料H2 / PostgreSQL持久化
原則：前端做體驗；真正的授權與資料正確性在後端。隱藏按鈕只是 UX，Spring Security 必須擋住直接打 API。
