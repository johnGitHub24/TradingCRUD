# TradingCRUD — 前後端 API 串接說明

> **用途：** 說明 Vue 3 前端、Node BFF、Spring Boot 後端之間的 API 契約與資料流。  
> **架構參考：** APIGatewayMQ 文件體系（路由總覽 → 請求/回應 → 錯誤碼 → 驗證步驟）。

---

## 1. 三層串接總覽

```text
┌─────────────────────────────────────────────────────────────────┐
│  Layer 1：Vue 3 前端（frontend/）                                │
│  LoginView / OrdersView → api/client.js（Axios）                 │
├─────────────────────────────────────────────────────────────────┤
│  Layer 2：傳輸層（開發 Vite proxy / 正式 Node BFF）               │
│  /api/v1/* → 轉發至 Spring Boot :8083                            │
├─────────────────────────────────────────────────────────────────┤
│  Layer 3：Spring Boot 後端（src/main/java）                       │
│  AuthController / OrderController → Service → JPA → DB           │
└─────────────────────────────────────────────────────────────────┘
```

| 模式 | 前端 URL | API 轉發 | 說明 |
|------|----------|----------|------|
| 開發 | http://localhost:5173 | Vite `vite.config.js` proxy | 熱更新、快速開發 |
| 正式 | http://localhost:3000 | Node `server/server.js` proxy | 單一入口、靜態檔服務 |
| 直連 API | http://localhost:8083 | 無 | Swagger、Postman、整合測試 |

## 2. 前端 API 客戶端對照表

檔案：`frontend/src/api/client.js`

| 前端函式 | HTTP | 後端端點 | 後端類別 | 需 Token | 需 ADMIN |
|----------|------|----------|----------|----------|----------|
| `login(u, p)` | POST | `/api/v1/auth/login` | AuthController | 否 | — |
| `fetchOrders(params)` | GET | `/api/v1/orders` | OrderController | 是 | 否 |
| `createOrder(body)` | POST | `/api/v1/orders` | OrderController | 是 | 是 |
| `updateOrder(id, body)` | PUT | `/api/v1/orders/{id}` | OrderController | 是 | 是 |
| `deleteOrder(id)` | DELETE | `/api/v1/orders/{id}` | OrderController | 是 | 是 |
| `batchCreateOrders(arr)` | POST | `/api/v1/orders/batch` | OrderBatchController | 是 | 是 |
| `batchDeleteOrders(ids)` | DELETE | `/api/v1/orders/batch` | OrderBatchController | 是 | 是 |

## 3. JWT 串接流程

### 3.1 登入（前台 → 後台）

```text
LoginView.handleLogin()
  → client.login(username, password)
  → POST /api/v1/auth/login
  → AuthController.login()
  → AuthService.login() → JwtService.generateToken()
  ← LoginResponse { accessToken, role, expiresIn }
  → stores/auth.js setSession() → localStorage
  → router.push('/orders')
```

### 3.2 受保護請求

```text
OrdersView.loadOrders()
  → client.fetchOrders()
  → axios interceptor 自動加：Authorization: Bearer <token>
  → JwtAuthenticationFilter 解析 Token
  → OrderController.list()
  ← PagedResponse { data[], meta }
```

### 3.3 Token 失效

```text
後端回 401
  → axios response interceptor
  → auth.logout() + window.location = '/login'
```

## 4. CRUD 串接範例

### 4.1 新增訂單（前台 → DB）

**前端送出（OrdersView.handleSubmit）：**

```json
{
  "clientOrderId": "o-1734567890",
  "symbol": "BTCUSDT",
  "side": "BUY",
  "quantity": 0.5,
  "price": 65000
}
```

**後端處理鏈：**

```text
OrderController.create(@Valid CreateOrderRequest)
  → @PreAuthorize("hasRole('ADMIN')")
  → OrderService.create()
       existsByClientOrderId? → 409
       OrderMapper.toEntity() → status=NEW
       OrderRepository.save() → INSERT orders
  → 201 + Location: /api/v1/orders/{id}
```

**前端收到後：** `showToast('訂單已建立')` → `loadOrders()` 重新載入表格

### 4.2 分頁查詢

**前端：**

```javascript
fetchOrders({ page: 0, size: 20, symbol: 'BTCUSDT', status: 'NEW' })
```

**後端 Query：** `GET /api/v1/orders?page=0&size=20&symbol=BTCUSDT&status=NEW`

**回應結構（前後端共用契約）：**

```json
{
  "data": [ { "id": 1, "clientOrderId": "...", "status": "NEW", ... } ],
  "meta": { "page": 0, "size": 20, "total": 42 }
}
```

## 5. 錯誤處理串接

| 後端 errorCode | HTTP | 前端處理位置 |
|----------------|------|--------------|
| VALIDATION_FAILED | 400 | formError / showToast |
| BAD_CREDENTIALS | 401 | LoginView error 區塊 |
| UNAUTHORIZED | 401 | axios interceptor 登出 |
| FORBIDDEN | 403 | showToast |
| ORDER_NOT_FOUND | 404 | showToast |
| DUPLICATE_ORDER | 409 | formError |

後端統一格式：`application/problem+json`（見 `GlobalExceptionHandler`）

## 7. 驗證步驟（DoD）

```powershell
# 1. 後端測試
.\scripts\check.ps1

# 2. 啟動後端
.\gradlew.bat bootRun

# 3. API smoke
.\scripts\verify-db.ps1

# 4. 前端 dev
cd frontend && npm run dev
# 手動：登入 → 新增 → 編輯 → 刪除 → 批次

# 5. 正式模式
cd frontend && npm run build
cd ../server && npm start
# 開啟 http://localhost:3000
```
