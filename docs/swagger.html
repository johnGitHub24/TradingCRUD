API 分組（實際 Controller）

  • Auth：POST /api/v1/auth/login、GET /api/v1/auth/me
  • Orders：CRUD /api/v1/orders
  • BATCH：POST/DELETE /api/v1/orders/batch（部分失敗 207）

認證與範例流程

  • JWT Bearer；示範帳 admin／admin123。
  • 流程：login → 複製 accessToken → Swagger 右上 Authorize → Bearer <token>。
  • 刪除需 ADMIN 角色。
