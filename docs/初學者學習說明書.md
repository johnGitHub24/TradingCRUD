## 3. 第一次 API 呼叫

### Step 1：登入

```powershell
$body = '{"username":"admin","password":"admin123"}'
$resp = Invoke-RestMethod -Uri "http://localhost:8083/api/v1/auth/login" `
  -Method POST -ContentType "application/json" -Body $body
$token = $resp.accessToken
```

### Step 2：新增訂單

```powershell
$headers = @{ Authorization = "Bearer $token" }
$order = '{"clientOrderId":"demo-001","symbol":"BTCUSDT","side":"BUY","quantity":0.5,"price":65000}'
Invoke-RestMethod -Uri "http://localhost:8083/api/v1/orders" `
  -Method POST -Headers $headers -ContentType "application/json" -Body $order
```

### Step 3：一鍵驗證

```powershell
.\scripts\verify-db.ps1
```

## 5. Swagger 操作步驟

1. 開啟 http://localhost:8083/swagger-ui.html
2. 展開 `POST /api/v1/auth/login`，Try it out，輸入 admin/admin123
3. 複製回應中的 `accessToken`
4. 點右上角 **Authorize**，輸入 `Bearer <token>`
5. 測試 `POST /api/v1/orders`、`GET /api/v1/orders`

## 6. 常見問題

| 問題 | 解法 |
|------|------|
| Gradle 版本錯誤 | 執行 `.\scripts\env.ps1` 設定 JDK 21 |
| 401 Unauthorized | 重新登入取得 Token |
| 403 Forbidden | 需 ADMIN 角色才能寫入 |
| 409 Duplicate | clientOrderId 已存在，換新 ID |
| 前端 API 失敗 | 確認後端 :8083 已啟動 |
