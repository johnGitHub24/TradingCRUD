# TradingCRUD — 功能流程說明

> 每個 API「做什麼、怎麼跑」，含 Mermaid 流程圖。

---

## 1. 登入流程

```mermaid
sequenceDiagram
    participant C as Client/Vue
    participant AC as AuthController
    participant AS as AuthService
    participant AM as AuthenticationManager
    participant JS as JwtService
    participant DB as app_users

    C->>AC: POST /auth/login {username, password}
    AC->>AS: login(LoginRequest)
    AS->>AM: authenticate()
    AM->>DB: 查詢 + BCrypt 驗證
    AM-->>AS: Authentication
    AS->>JS: generateToken(username, role)
    JS-->>AS: JWT
    AS-->>AC: LoginResponse
    AC-->>C: 200 {accessToken, role, ...}
```

---

## 2. 受保護請求（JWT Filter）

```mermaid
sequenceDiagram
    participant C as Client
    participant F as JwtAuthenticationFilter
    participant JS as JwtService
    participant SC as SecurityContext
    participant CTL as Controller

    C->>F: Authorization: Bearer <token>
    F->>JS: isValid(token)
    JS-->>F: true + claims
    F->>SC: setAuthentication()
    F->>CTL: 繼續 Filter Chain
    CTL-->>C: 200/201/...
```

未帶 Token → `RestAuthenticationEntryPoint` → 401

---

## 3. 新增訂單（CRUD Create）

```mermaid
sequenceDiagram
    participant C as Client
    participant OC as OrderController
    participant OS as OrderService
    participant R as OrderRepository
    participant DB as orders

    C->>OC: POST /orders + Bearer Token
    Note over OC: @PreAuthorize ADMIN
    OC->>OS: create(@Valid request)
    OS->>R: existsByClientOrderId()
    alt 已存在
        OS-->>C: 409 DUPLICATE_ORDER
    else 不存在
        OS->>R: save(entity)
        R->>DB: INSERT
        OS-->>OC: OrderResponse
        OC-->>C: 201 + Location
    end
```

---

## 4. 查詢列表（分頁 + 篩選）

```text
GET /api/v1/orders?symbol=BTCUSDT&status=NEW&page=0&size=20
  → OrderController.list()
  → OrderService.list() [@Transactional(readOnly=true)]
  → OrderRepository.search() [JPQL + Pageable]
  → PagedResponse { data[], meta { page, size, total } }
```

---

## 5. 批次新增

```text
POST /api/v1/orders/batch { orders: [...] }
  → OrderBatchController.batchCreate()
  → OrderService.batchCreate()
       for each order:
         - 批次內重複 → failures[]
         - DB 已存在 → failures[]
         - 成功 → createdIds[]
  → failed==0 ? 201 : 207
```
